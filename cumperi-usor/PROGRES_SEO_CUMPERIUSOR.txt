📝 PAȘI DE URMAT PENTRU IMPLEMENTARE SEO ÎN WORDPRESS:
================================================================================

🔲 2. IMPORT CONȚINUT SEO ÎN YOAST (DE FĂCUT)
   ─────────────────────────────────────────────────────
   Opțiuni de implementare:
   
   A) MANUAL (recomandat pentru 40 produse):
      • Deschide fiecare produs în WordPress → Edit
      • Scroll la panoul Yoast SEO
      • Copiază "Yoast SEO Title" din Excel în câmpul "SEO title"
      • Copiază "Yoast Meta Description" în câmpul "Meta description"
      • Update produs
   
   B) CU PLUGIN (pentru cataloage mari):
      • Instalează "WP All Import Pro" + Yoast SEO Add-On
      • Importă Excel-ul și mapează câmpurile:
        - Yoast SEO Title → _yoast_wpseo_title
        - Yoast Meta Description → _yoast_wpseo_metadesc
   
   C) CU SQL (avansat):
      • Update direct în wp_postmeta folosind ID-ul produsului


🔲 3. ACTUALIZARE ALT TEXT PENTRU IMAGINI (DE FĂCUT)
   ─────────────────────────────────────────────────────
   • WordPress Admin → Media → Library
   • Pentru fiecare imagine de produs:
     - Click pe imagine
     - În câmpul "Alt Text" copiază valoarea din Excel
     - Save
   
   SAU folosește plugin: "Media Library Alt Fields" pentru bulk edit


🔲 4. CONFIGURARE SEO TEHNIC ÎN YOAST (DE FĂCUT)
   ─────────────────────────────────────────────────────
   WordPress → Yoast SEO → Settings:
   
   a) General:
      • Verifică Site Representation (Organization/Person)
      • Adaugă logo și favicon
   
   b) Content Types → Products:
      • Schema type: Product
      • Show in search results: ON
      • SEO title template: %%title%% - Cumpără Online | CumperiUsor
      • Meta description template: %%excerpt%% Comandă acum cu livrare rapidă!
   
   c) Taxonomies → Product Categories:
      • Show in search results: ON
      • Adaugă descrieri unice pentru fiecare categorie

📍 PAȘI PENTRU SEO LOCAL / GEO (DE FĂCUT):
================================================================================

🔲 5. CONFIGURARE LOCAL SEO (GEO)
   ─────────────────────────────────────────────────────
   
   A) GOOGLE BUSINESS PROFILE:
      • Creează/verifică profilul pe https://business.google.com
      • Adaugă:
        - Numele exact al afacerii
        - Adresa fizică (dacă ai sediu)
        - Număr telefon
        - Program de lucru
        - Categorii relevante (ex: "Magazin de electronice")
        - Fotografii cu produse/sediu
        - Link către site
   
   B) SCHEMA MARKUP LOCAL BUSINESS:
      • Instalează plugin: "Schema Pro" sau "Rank Math"
      • Adaugă LocalBusiness schema cu:
        - @type: "Store" sau "ElectronicsStore"
        - name, address, telephone
        - openingHours
        - geo (latitude, longitude)
        - areaServed: "Romania"
   
   C) PAGINI LOCALE:
      • Creează pagină "Contact" cu:
        - Adresă completă
        - Google Maps embed
        - Formular contact
      • Creează pagină "Livrare" cu:
        - Zone de livrare
        - Timpuri estimative pe județe
        - Costuri livrare


🔲 6. OPTIMIZARE PENTRU CĂUTĂRI LOCALE (DE FĂCUT)
   ─────────────────────────────────────────────────────
   
   • Adaugă în footer:
     - Adresa completă cu localitate/județ
     - Telefon cu link clickabil (tel:)
     - Email cu link (mailto:)
   
   • În titluri și descrieri, include când e relevant:
     - "Livrare în toată România"
     - "Comandă online din România"
     - Menționează orașe mari: București, Cluj, Timișoara, Iași
   
   • Creează conținut local:
     - Blog post: "Unde cumperi boxe Bluetooth în [Oraș]"
     - FAQ: "Cât durează livrarea în [Județ]"


🔲 7. SETĂRI TEHNICE GEO (DE FĂCUT)
   ─────────────────────────────────────────────────────
   
   A) HREFLANG (dacă ai mai multe limbi):
      <link rel="alternate" hreflang="ro" href="https://cumperiusormarket.ro/" />
   
   B) GOOGLE SEARCH CONSOLE:
      • Verifică site-ul
      • Setează țara țintă: România
      • Trimite sitemap: /sitemap_index.xml
   
   C) STRUCTURED DATA PENTRU PRODUSE:
      • Verifică că Yoast/WooCommerce generează schema Product
      • Testează cu: https://search.google.com/test/rich-results
